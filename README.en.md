<h2>DailyHot</h2>
<p>An API that aggregates trending data.</p>
</div>

## 🚩 Features

- Fast responses for convenient development
- RSS and JSON output modes
- Multiple deployment methods
- A simple route structure for adding sources

## 👀 Main repository

This repository is intended for `Vercel` deployment only. For more information, visit [DailyHotApi](https://github.com/imsyy/DailyHotApi).

## ⚙️ Deployment

Use the button below for one-click deployment, or deploy manually.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/imsyys-projects/clone?repository-url=https%3A%2F%2Fgithub.com%2Fimsyy%2FDailyHotApi-Vercel)

## ⚙️ Automatic updates

This repository uses [GitHub Actions](https://github.com/imsyy/DailyHotApi-Vercel/actions) to fetch the latest version daily at 00:00. The workflow can also be started manually.
